# Hailah Alhejjei Portfolio

A responsive, accessible static portfolio.

## Preview
Open `index.html` in any browser.

## GitHub Pages deployment
1. Create a public repository named `HailahAlhejjei.github.io`.
2. Upload `index.html` and `Hailah_Alhejjei_CV_2026.pdf` to the `main` branch.
3. In **Settings → Pages**, select **Deploy from a branch**, then `main` and `/ (root)`.
4. The site will publish at `https://hailahalhejjei.github.io`.

## Vercel deployment
Import the GitHub repository into Vercel and select **Deploy**. It is a static site and requires no configuration.
